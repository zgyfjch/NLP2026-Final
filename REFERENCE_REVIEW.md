# Reference review for the course project

The user asked to examine other submissions and projects. These public examples informed presentation and reproducibility, not the implementation or measured findings.

| Example | Observed useful practice | Decision for NewsLens |
|---|---|---|
| [NKU Homework 1 repository](https://github.com/Burhan-Hu/NLP-HW-1) | Separates data, model scripts, results, report, and clear reproduction commands. | Retain our independent split checksum, per-row predictions, exact environment, and a single runnable demo entry point. No code or scores were copied. |
| [Public end-to-end news labeling project](https://github.com/asaee/ML_capstone_springboard) | Describes preprocessing, baseline experiments, deployment, and testing in a coherent project narrative. | Keep the ACL final manuscript organized around a problem, a local system, its evaluation, and limitations. Our calibrated review and exact term-margin logic are different project modules. |
| [Stanford CS230 news classification report](https://cs230.stanford.edu/projects_winter_2019/reports/15795079.pdf) | Uses an English research-report structure with motivation, methodology, results, and discussion. | Keep the final course report in English and make model comparisons, evaluation conditions, and limits explicit. No text or results were imported. |

The course requirements are the authority for length, ACL style, stage submissions, and track definitions. Public repositories are examples, not substituted specifications.
